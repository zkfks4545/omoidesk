### 🚀 Key Improvements (리팩토링 성과)
- **State Management**: `index.jsp`를 데이터 중심점(Source of Truth)으로 설정하여 전역 상태를 단일화하고, 복잡한 비동기 환경에서의 데이터 정합성 확보
- **Performance Optimization**: **이벤트 위임(Event Delegation)** 기법을 통해 개별 리스너를 단일 부모 요소로 통합하여 메모리 점유율을 획기적으로 개선
- **UX Continuity**: DOM 노드를 파괴하지 않고 클래스 토글 방식을 채택하여 페이지 전환 시에도 시스템 애니메이션 및 상태가 끊김 없이 유지되도록 설계
- **Modern Backend Integration**: Oracle SQL의 안정성과 **Supabase**의 유연함을 결합하여 데이터 확장성 및 실시간 응답성 고려
- **Version Control**: **Sourcetree**를 활용한 시각적 브랜치 관리 및 Git 컨벤션 준수로 체계적인 개발 히스토리 관리

### 🏠 Core Features (전체 주요 기능)
- **Asynchronous Mini-Hompy Architecture**: `router.js`와 History API를 활용한 **SPA(Single Page Application)** 환경을 구축하여, 페이지 전체 새로고침 없이 상단 메뉴와 콘텐츠가 부드럽게 교체되는 현대적 미니홈피 구현
- **Dynamic Identity-Based UI**: 방문한 미니홈피의 주인 PK와 현재 접속 세션을 대조하여 홈피 주인(관리 권한)과 방문자(조회 권한)에게 최적화된 맞춤형 인터페이스 및 기능을 동적으로 제공
- **Hybrid Data Management System**: **Oracle SQL**을 통한 엄격한 관계형 데이터 처리와 **Supabase**의 실시간성 및 확장성을 결합하여, 방명록/게시판/프로필 관리 전반에서 안정적인 데이터 트랜잭션 보장
- **Customizable Interaction Components**: 모달(Modal) 시스템, AJAX 탭 네비게이션, 드래그 앤 드롭 등 다양한 대화형 컴포넌트를 직접 구현하여 사용자 몰입감 극대화
